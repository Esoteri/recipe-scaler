Python Recipe Scaler

A beginner Python project that scales ingredient quantities using a Python dictionary and a scaling factor.

Version 0.1
The program:
Stores ingredients and quantities in a Python dictionary.
Multiplies ingredients by a specified scaling factor.
Creates a new dictionary containing the scaled quantities.
Prints the original and scaled recipes.

How to run
Run the program using Pythong

```python recipe-scaler.py```

Current limitiations
Recipes are hardcoded.
The scaling factor must be changed manually.
Units of measurement are not currently stored.
There is no interactive user input.

Future improvements
Original and desired serving sizes.
Interactive user input.
Ingredient measuring units.
Support for multiple recipes.
